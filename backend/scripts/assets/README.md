# Imágenes demo de Lessons

`book.png` y `cup.png` son dibujos geométricos originales creados para la prueba local (240 × 180). No son assets oficiales de Alma. Se guardan como data URLs PNG en la configuración demo de matching para que Android pueda mostrarlos sin proveedor remoto, credenciales ni servidor de medios.

Solo los importa el tooling de desarrollo `lessons-demo-data.ts`.
