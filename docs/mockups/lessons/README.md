# Referencias visuales — Lessons v1

Estos nueve mockups de La Teacher Alma orientan la próxima vertical slice Lessons v1. Activities, Lesson Summary y Lesson Result forman parte del flujo visual de una lección. Son referencias de diseño, no contratos de API ni reglas de negocio; los valores, controles y estados ilustrados no fijan su comportamiento definitivo.

## Contenido y resumen

- [lesson-content.png](lesson-content.png): «Nice to meet you!», contenido explicativo, «En resumen», ejemplos, video de La Teacher Alma y CTA Continuar.
- [lesson-summary.png](lesson-summary.png): «Resumen de la lección», puntos aprendidos, frases clave, actividades completadas y CTA Finalizar lección.

## Actividades

- [fill-blank-text.png](../activities/fill-blank-text.png): «Completa la oración», imagen, campo de respuesta libre, Pista y Verificar.
- [fill-blank-options.png](../activities/fill-blank-options.png): completar la oración seleccionando Hello / Goodbye / Please; Verificar.
- [match-word-image.png](../activities/match-word-image.png): «Hello and Goodbye», asociación de palabras e imágenes mediante conectores; Comprobar.
- [multiple-choice-feedback.png](../activities/multiple-choice-feedback.png): «¿Qué responderías?», opción seleccionada, feedback correcto visible y Continuar.

## Resultados

- [lesson-result-review.png](../results/lesson-result-review.png): lección completada, recompensas ilustradas, progreso y cuatro ejercicios para repasar con temas/errores; Siguiente lección, Repasar errores y Volver a la ruta.
- [lesson-result-perfect.png](../results/lesson-result-perfect.png): resultado excelente, 10/10, recompensas ilustradas y sin errores para repasar; Siguiente lección y Volver a la ruta.
- [lesson-result-standard.png](../results/lesson-result-standard.png): resultado no perfecto, 8/10, monedas, racha, progreso y dos ejercicios para repasar; Siguiente lección y Volver a la ruta.

## Alcance de la referencia

Las futuras implementaciones deben conservar la dirección general de Courses v1: interfaz clara, azul primario, rojo para CTA, cards redondeadas y gamificación ligera.

Este índice no define contratos API de Lessons, estructura definitiva de attempts, cálculo de score, monedas, rachas, recompensas, paywalls, audio, hints, review definitivo ni reglas adicionales de finalización. Esos temas se definirán posteriormente; su presencia en las imágenes es únicamente ilustrativa. No se inicia aquí la implementación de Lessons v1.
