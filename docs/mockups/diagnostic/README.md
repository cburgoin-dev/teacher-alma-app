# Diagnostic Mobile v1 — referencias históricas

Las cinco imágenes originales se conservan como referencias visuales. Mandan `docs/diagnostic-semantics-v1.md`, `docs/diagnostic-api-contract-v1.md`, `docs/diagnostic-v1-freeze.md` y `docs/home-diagnostic-integration-v1.md`, junto con el contrato Backend implementado.

- `diagnostic-intro-primary.png`: referencia primaria de Intro, jerarquía y CTA.
- `diagnostic-question-primary.png`: referencia primaria visual de Questions; se reutilizan los componentes actuales de Lessons y su Matching TAP.
- `diagnostic-result-a1-primary.png`: referencia primaria de Result; el nivel y curso siempre provienen del servidor.
- `home-new-diagnostic.png`: referencia de integración NEW cuando `hero.diagnosticAvailable` es true. Se adapta al Home actual, sin reconstruir el Home histórico.
- `diagnostic-result-commercial-secondary.png`: referencia visual secundaria solamente.

Son obsoletos el botón **Saltar**, cualquier chip de nivel sin fuente pública, compra única, paywall propio, B2 hardcodeado, fortalezas/áreas de refuerzo inventadas y start directo de Course. Tampoco se copian cantidades, duración, puntuaciones o acceso comercial del dibujo como datos reales.

Las ilustraciones de Alma pertenecen a estos mockups; no son assets de producción autorizados para recortar. Intro usa el branding oficial existente y una composición limpia. Result sigue funcionando sin las secciones cualitativas nulas del contrato. La aceptación visual física de Android y una futura ilustración oficial quedan documentadas en `mobile/DIAGNOSTIC.md`.
