# Decorative course covers

Generated with the built-in image_gen tool on 2026-09-21 for the second Courses visual iteration. These are decorative fallback images, not course content, real location claims, or persisted domain data. Remote coverUrl takes priority. No labels, progress or access values are baked into the images.

Mapping: A1 → London; A2 → New York; B1/B2 → Tower Bridge; C1/C2 → Manhattan. Unknown or absent levels use London without inventing a level badge. The A1/A2 decorative captions are rendered as text by CourseCover.

## Prompt set

Each scene below used this prompt template:

> Use case: photorealistic-natural. Asset type: decorative fallback course cover for a polished mobile English learning app. Create one premium travel editorial image, NOT a UI mockup. [SCENE] Landscape 3:2 composition. Important landmarks concentrated near the middle so center cropping into a narrow portrait thumbnail retains recognizable subject, but the full composition also works as a wide hero banner. Clean vibrant photographic detail, slightly art-directed educational cover mood. No text, no lettering, no badges, no flags, no watermark, no phone frame. No UI elements.

- a1-london.png: London, the Big Ben clock tower and Westminster with a red double decker bus in the foreground. Bright blue sky, soft white clouds, warm stone, rich red bus, inviting daylight.
- a2-new-york.png: New York, the Statue of Liberty in the foreground with Manhattan skyline beyond. Clear blue sky, soft white clouds, turquoise statue and blue city atmosphere, inviting daylight.
- b1-tower-bridge.png: London Tower Bridge with its twin stone towers and blue suspension details, glowing peach and pale lavender sunset sky reflected in the river. Warm elegant light.
- c1-manhattan.png: New York Manhattan skyline with Empire State Building as the central subject at golden hour, pink peach sky fading into pale blue, luminous windows, sophisticated warm atmosphere.
